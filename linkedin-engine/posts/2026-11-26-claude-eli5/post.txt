Stuck with Claude? You're probably not missing a trick. You're missing the basics (and they change every few months).

These are the 6 lessons I'd teach anyone starting today, from my free guides:

LESSON 1: Claude remembers you in four places, not one.

Custom instructions: how you like things, in every chat.
Projects: the files for one client or one piece of work.
Connectors: access to your other apps, like your drive or calendar.
Skills: one job, done your way, whenever a request needs it.

Put each thing in the wrong place and you'll repeat yourself forever. Which goes where: https://mojeedabisiga.com/learn/guides/skill-or-something-else/

LESSON 2: Paste this to start any big request

"Goal: [what it's for, in one line]
Background: [who it's for, what they already know]
Done when: [what finished looks like]
Before you start, ask me the five questions you most need answered."

Don't write "Write me a report on sales."
Write "Help the board decide whether to keep selling in Ghana. One page, three options, each with its cost."

The full method: https://mojeedabisiga.com/learn/guides/brief-claude-like-a-colleague/

LESSON 3: Never trust a number you haven't seen worked out.

Before your real question, ask Claude to describe the file: rows, date range, missing values, repeated rows, totals rows. Then ask for the working, with the row count after every step. Guide: https://mojeedabisiga.com/learn/guides/ask-claude-about-your-data/

LESSON 4: Turn the jobs you repeat into skills

Switch on: Settings → Capabilities → "Create and edit files".
Install: Customize → Skills → + → Upload a skill.
My rule: explained it 3 times? Make it a skill. Here's how: https://mojeedabisiga.com/learn/p/make-your-first-skill/

LESSON 5: Don't start over. Correct it.

Treat the first answer like a colleague's draft. Say what to change AND why: "Shorter, because the board reads it on their phones." The why fixes every answer after it.

LESSON 6: Drop these 5 habits today

✦ Pasting AI numbers into a slide without seeing the working.
✦ Installing a skill you haven't read. It can run code.
✦ Putting passwords or API keys anywhere in a skill.
✦ Describing a style with adjectives. Paste an example instead.
✦ Three jobs in one skill. One skill, one job.
