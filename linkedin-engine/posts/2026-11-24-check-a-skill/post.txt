Read this before you install the next Claude skill someone sends you.

(Then send it to the person on your team who installs every new tool first.)

A skill isn't just a prompt.

It can carry scripts.
Code that runs when Claude uses it.

And skills load in layers.
Claude reads the instructions only when a request matches.
Scripts run, and only their results come back.

So you can use a skill for weeks without ever seeing what's inside.

The 2 real risks:

→ Prompt injection: hidden instructions that steer Claude into something you didn't ask for.
→ Data leaks: a script that sends your information somewhere.

Here's the 5-minute check I run on every skill I didn't write:

1. The source
Someone you trust? Even a skill a colleague shares deserves a look first.

2. SKILL.md
Read it top to bottom. Does it stay on the one job it promises?

3. Every script
Look for anything that downloads software or sends information to a website.

4. Secrets
No passwords, API keys or personal data. Not in any file.

5. A harmless test
Switch it on. Try it on files that don't matter first.

On Enterprise?
Owners can turn on skill scanning, which checks uploaded skills for malicious content.

Treat an unknown skill like an unknown app.
