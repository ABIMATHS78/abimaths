Your Claude skill isn't broken.

Its description is.

Here's the part nobody tells you:

Claude decides when to use a skill from its description alone.

Not the steps.
Not the examples.
Not the long instructions you wrote below it.

Most of the time, that one line is the only part of your skill Claude sees.

Write it badly, and your skill sits there unused.

The 3 mistakes I see most:

→ It says what the skill does, but never when.
→ It's written as "I help you..." instead of in the third person.
→ It's vague: "Helps with reports."

Here's what a strong one looks like:

"Turns the week's notes and numbers into our team's weekly report format. Use when someone asks for the weekly report or pastes weekly updates."

What it does.
When to use it.
Under 200 characters (the limit in the Claude apps).
No tags in angle brackets.

Then test it with 5 requests:
1. Write 3 that should use the skill.
2. Write 2 that shouldn't.
3. Try all 5.

Claude missed one?
Don't touch the steps.
Rewrite the description first.
