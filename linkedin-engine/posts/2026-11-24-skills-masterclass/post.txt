You paste the same instructions into Claude every day.

A skill ends that in about an hour. Here's the whole thing, step by step (save this):

LESSON 1: Know what a skill is.
A folder with one required file: SKILL.md.
Its name is the command you type (/weekly-report).
Its description tells Claude when to use it.
Claude reads the full instructions only when a request needs them. So install as many as you like.
Full guide: https://mojeedabisiga.com/learn/guides/claude-skills-from-zero/

LESSON 2: Check it should be a skill.
Preferences for every chat → custom instructions.
Background for one piece of work → a project.
Your other apps → a connector.
A job you've explained 3 times → a skill.
The 2-question test: https://mojeedabisiga.com/learn/guides/skill-or-something-else/

LESSON 3: Switch skills on.
Settings → Capabilities → "Create and edit files".
(Older layout: "Code execution and file creation".)
Team plans: on by default. Enterprise: an owner turns them on first.

LESSON 4: Write the SKILL.md.
Name: lowercase & hyphens, 64 characters max.
Then numbered steps, the mistakes to avoid, one example. Under 500 lines.
Copy the template: https://mojeedabisiga.com/learn/library/

LESSON 5: Spend your time on ONE line.
Claude picks a skill from its description alone.
What it does AND when to use it. Third person. 200 characters max.
"Turns the week's notes into our team's weekly report. Use when someone asks for the weekly report."
Before & after rewrites: https://mojeedabisiga.com/learn/p/skill-description/

LESSON 6: Zip the folder, not the files.
Customize → Skills → + → Create skill → Upload a skill.
Upload the zip as it is. Don't unzip it. Then switch it on.

LESSON 7: Test it with 5 requests.
3 that should use it. 2 that shouldn't.
Claude missed one? Fix the description, not the steps.
The full walkthrough: https://mojeedabisiga.com/learn/p/make-your-first-skill/

LESSON 8: Never switch on a skill you haven't read.
A skill can run code. Read every script.
No passwords or API keys inside. Ever.
The 5-minute check: https://mojeedabisiga.com/learn/p/check-a-skill-before-you-trust-it/

BONUS: In Claude Code, put the folder in ~/.claude/skills/ (every project) or .claude/skills/ (commit it for your team). /skills lists what's installed.
