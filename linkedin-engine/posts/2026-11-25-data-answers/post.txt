Claude will answer any question about your spreadsheet.

Confidently. Even when the number is wrong.

A right answer and a wrong one sound exactly alike. Here's how to tell them apart (10 minutes, 5 steps):

Step 1. Clean the file first.
One header row. One table per sheet.
Delete the totals row (it gets counted twice).
Swap names & emails for an ID.

Step 2. Make it describe the data BEFORE it answers.
"Before answering anything, describe this file: rows, columns, date range, missing values, numbers stored as text, repeated rows, and any totals row. Don't analyse anything yet."
Wrong row count? Fix the file now, not after the slide goes out.

Step 3. Define your terms.
"Revenue" = which column? "Last quarter" = which months? Cancelled orders in or out?
Every word you leave vague, Claude fills with a guess.

Step 4. Ask for the working.
"List each step, the number of rows after each step, and the formula you used. Then give the answer."
4,812 rows turning into 9,624 after a join? Now you'll see it.

Step 5. Check it two ways.
→ Same number, different method (pivot vs formula)
→ Three rows checked by hand
→ "What could make this answer wrong? List the three most likely problems."

The 5 traps behind most wrong answers:
☑ Numbers stored as text
☑ Repeated rows
☑ Totals counted twice
☑ Gaps in the dates
☑ Joins that multiply rows
