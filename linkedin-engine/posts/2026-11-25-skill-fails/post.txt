Most first Claude skills fail before Claude ever reads them.

7 reasons it happens, and the fix for each (save this before you upload yours):

1. You zipped the files, not the folder.
The zip must contain weekly-report/SKILL.md. Files loose at the top = failed upload.
→ Right-click the FOLDER, then Compress (Mac) or Send to → Compressed folder (Windows).
→ Upload the zip as it is. Don't unzip it.

2. Skills can't run yet.
→ Settings → Capabilities → turn on "Create and edit files".
(Enterprise? An owner has to turn skills on first.)

3. The switch is off.
It's off more often than you'd think.
→ Customize → Skills → check the toggle.

4. The name breaks a rule.
Lowercase, numbers & hyphens only. 64 characters max. Same as the folder. No "claude" in it.
→ weekly-report, not Weekly Report.

5. The description says nothing.
Claude picks a skill from that one line alone.
Weak: "Helps with reports."
Strong: "Turns the week's notes into our weekly report format. Use when someone asks for the weekly report."
→ The full rules: https://mojeedabisiga.com/learn/p/skill-description/

6. It's three jobs pretending to be one.
→ One skill, one job. Split it.

7. You never tested it.
The step everyone skips.
→ 3 requests that SHOULD use it.
→ 2 that shouldn't.
All five behave? Done.

Claude still ignores it?
Fix it in this order:
☑ Check the switch
☑ Name it: "Use my weekly-report skill on these notes."
☑ Rewrite the description, then run the five again
