Everything you need to know about Claude skills fits on one page.

Here it is (save it):

✦ What a skill is
A folder that teaches Claude one job.
One required file: SKILL.md.
Its name is the command you type. Its description tells Claude when to use it.

✦ How it's different
Instructions apply to every chat.
Projects apply inside one project.
Connectors reach your other apps.
A skill applies only when a request needs it, in any chat.

✦ Install one in 4 steps
1. Get the zip (yours, or one you trust). Don't unzip it.
2. Settings → Capabilities → "Create and edit files".
3. Customize → Skills → + → Create skill → Upload a skill.
4. Check the switch is on.

✦ In Claude Code
Unzip it into ~/.claude/skills/ for every project.
Or into a project's .claude/skills/ folder, and commit it.

✦ Make your own
Name: lowercase & hyphens, 64 characters max.
Description: what it does AND when to use it, 200 characters max.
Instructions: under 500 lines.

✦ Test it
Write 3 requests that should use it & 2 that shouldn't.
If Claude misses one, fix the description first.

✦ Never
Switch on a skill you haven't read.
Put passwords or API keys inside one.
