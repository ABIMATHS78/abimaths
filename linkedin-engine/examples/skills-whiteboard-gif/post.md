```text
Learn Claude skills from zero in 5 minutes. I drew the whole thing on one board:

MIN 1 - Know what a skill is
A folder with one required file: SKILL.md.
Its first lines hold a name & a description.
Claude reads that description to decide when to use it.

MIN 2 - Turn skills on
Settings → Capabilities → "Create and edit files".
(Older layouts call it "Code execution and file creation".)

MIN 3 - Get one
Ready-made: Customize → Skills → + → Browse skills.
(Partners like Notion, Figma & Atlassian have skills there.)
Or write your own: a folder with a SKILL.md inside.

MIN 4 - Upload yours
Zip the folder, not the files inside it.
Customize → Skills → + → Create skill → Upload a skill.
Upload the zip as it is. Don't unzip it.

MIN 5 - Use it
Just ask. Claude picks the skill when your request matches.
To be sure, name it: "Use my weekly-report skill on these notes."

ALWAYS - Stay safe
A skill can contain code. Treat it like an app.
Read every file before you switch it on.
Never put passwords, API keys or personal data in a skill.

On a Team plan, skills are on by default.
On Enterprise, an owner turns them on first.

My rule: once you've explained the same thing to Claude three times, make it a skill.

Save this for the next time you catch yourself retyping a prompt.

More about my work: https://mojeedabisiga.com/
```
