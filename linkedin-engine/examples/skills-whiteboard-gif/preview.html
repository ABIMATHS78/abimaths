Here's the whole thing (I drew it out for you): MIN 1 - Know what a skill is A folder with one file: SKILL.md. Its first lines hold a name & a description. Claude reads that description to decide when to use it. MIN 2 - Turn it on Settings → Capabilities → "Create and edit files". (Older layouts call it "Code execution and file creation".) MIN 3 - Upload it Customize → Skills → + → Create skill → Upload a skill. Upload the zip as it is. Don't unzip it. MIN 4 - Use it Just ask. Claude picks the skill when your request matches. To be sure, name it: "Use my check-the-numbers skill on these sales figures." MIN 5 - Stay safe A skill can contain code. Treat it like an app. Read every file before you switch it on. Never put passwords, API keys or personal data in a skill. BONUS - Make your own Install skill-maker and say: "Help me make a skill for my weekly report." On a Team plan, skills are on by default. On Enterprise, an owner turns them on first.
