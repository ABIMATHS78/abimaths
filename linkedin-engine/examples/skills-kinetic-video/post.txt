You paste the same instructions into Claude every morning.

Then you correct the same mistakes. Every. Single. Day.

There's a fix:

A skill.

It's one folder with a SKILL.md file inside: your instructions, your format, your rules. Written once.

→ You upload it once (Customize → Skills).
→ Claude uses it whenever a request needs it.
→ It only loads when needed, so you can install many.

It works in the Claude app, in Claude Code & in Cowork.

I wrote 10 for the people I teach: learn-anything, quiz-me, research-brief, meeting-to-actions, check-the-numbers and 5 more.

Start with the task you repeat most. Make that your first skill.
