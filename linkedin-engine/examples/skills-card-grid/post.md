```text
I wrote 10 Claude skills for the people I teach. Here's what each one does (steal the ideas):

A skill is a small folder of instructions that teaches Claude one job, your way.

No more pasting the same long prompt.
No more explaining your format again.
No more correcting the same mistakes.

You install it once. Claude picks it up whenever a request needs it.

The 10 I wrote:

1. /learn-anything - any topic, step by step, from what you already know.
2. /quiz-me - turns your notes into practice questions, one at a time.
3. /research-brief - a short, sourced brief with a confidence level per finding.
4. /news-explainer - what happened, why it matters, who it affects.
5. /job-application - fits your CV & cover letter to one job ad, honestly.
6. /linkedin-post - posts in your own voice.
7. /meeting-to-actions - decisions, owners, deadlines & the follow-up email.
8. /presentation-planner - one message per slide, with speaker notes.
9. /check-the-numbers - proves the answer before it gives it.
10. /skill-maker - helps you build, check & zip your own.

How to install any skill (4 steps):

1. Get the skill's zip (yours, or one you trust). Don't unzip it.
2. Settings → Capabilities → turn on "Create and edit files".
3. Customize → Skills → + → Create skill → Upload a skill.
4. Check the switch is on. Then just ask.

No zip yet? Customize → Skills → + → Browse skills has ready-made ones from partners like Notion, Figma and Atlassian.

You can install as many as you like. Until a request needs one, Claude reads only each skill's name and description, so nothing slows down.

Read every file before you switch a skill on. Treat an unknown skill like an unknown app.

More about my work: https://mojeedabisiga.com/

♻️ Repost it for the colleague who still pastes the same prompt every morning.
```
