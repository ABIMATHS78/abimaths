# Strategy on one page

A strategy no one can remember doesn't guide anyone. Fit it on one page that every team can use to make choices.

## Ask first

If any of this is missing, ask for it in one short message:
- the strategy documents, plans or notes to work from;
- the time frame, such as the next one or three years;
- who will read the page: the leadership team, all staff, investors;
- what's already decided, and what's still open.

## Steps

1. **Write the ambition** in one sentence: where the organisation wants to be by the end of the period.
2. **Say where it will compete**: which customers, markets, products and channels, and which it will deliberately not pursue.
3. **Say how it will win**: the advantage it will build or use, and why others can't easily copy it.
4. **Choose three to five priorities.** Each needs an owner and a measure. If everything is a priority, ask which ones would survive a budget cut.
5. **Set the measures**: a few numbers that show progress, each with its starting point and target.
6. **Name what you'll stop doing**, so the priorities have the time and money they need.
7. **List the main risks and assumptions** that, if wrong, would change the strategy.

## Output

```
# <Organisation> strategy, <period>

**Ambition**: <one sentence>
**Where we compete**: <customers, markets, channels> · **Not**: <what we won't pursue>
**How we win**: <the advantage>

| Priority | Owner | Measure | Now | Target |
|---|---|---|---|---|

**We will stop**: <list>
**Key assumptions and risks**: <list>
```

## Rules

- **Make real choices.** If a line could describe any organisation, rewrite it.
- Never invent targets or numbers. Mark missing ones "to confirm".
- Keep the language plain enough for every team to repeat.
- Keep it to one page; link to the full plan for detail.
