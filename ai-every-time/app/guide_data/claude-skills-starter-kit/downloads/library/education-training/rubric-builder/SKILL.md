# Rubric builder

Build a rubric that shows learners what good work looks like before they start, and helps different markers reach the same judgement.

## Ask first

If any of this is missing, ask for it in one short message:
- the task brief and the learning outcomes it assesses;
- the learners' level;
- how many levels the rubric needs, and their names or marks (suggest four if there's no rule);
- any weighting, word count or grading scale the course already uses;
- a sample of past work, with names removed, to test the rubric against.

## Steps

1. **Pick the criteria.** Choose three to six, each tied to a learning outcome. Each criterion assesses one thing only, so a learner can do well on one and less well on another.
2. **Leave out what isn't being assessed.** Don't reward neatness, length or polish unless an outcome asks for it.
3. **Describe each level** in terms a marker can see in the work. Change the quality, not the quantity: "explains why each step works" says more than "explains some steps".
4. **Keep each row parallel.** Every descriptor in a row covers the same features, so the step from one level to the next is clear.
5. **Replace empty words.** Swap "good", "excellent" and "adequate" for what actually makes the work good.
6. **Decide the bottom of the scale**: what earns the lowest level, and what counts as "not yet shown".
7. **Weight the criteria** if some outcomes matter more, and check the marks add up.
8. **Test it.** Mark the sample work, or a strong, a middling and a weak imagined response, against the rubric. Fix any row where two levels could both fit.
9. **Write a learner version** as plain "I can…" statements, if the teacher wants one.

## Output

```
# Rubric for <task>, <level>
Outcomes assessed: <list>

| Criterion (weight) | <Level 4> | <Level 3> | <Level 2> | <Level 1> |
|---|---|---|---|---|
| <Criterion> (<x>%) | <descriptor> | <descriptor> | <descriptor> | <descriptor> |

Notes for markers: <borderline work, missing sections, word count>
Learner version: <optional "I can…" statements>
```

## Rules

- Never invent grade boundaries, mark schemes or the requirements of an exam or accrediting body. Write "to confirm" and ask the teacher to add them.
- Make every descriptor about the work itself, never a guess about the learner's effort, attitude or background.
- Check the wording for bias. Don't reward one style of English, one culture's examples, or resources only some learners can get, unless the outcome requires it.
- Don't penalise the same mistake under two criteria.
- Remove names from any sample work, and follow the school's data protection rules.
- The rubric supports marking. The teacher decides every mark and grade.

## Checklist before you finish

- [ ] Every criterion links to an outcome.
- [ ] Every level in a row describes the same features.
- [ ] A learner could read it and know how to reach the next level.
- [ ] Weights and marks add up.
