# Differentiated worksheet

Make one worksheet in three versions, so every learner works on the same objective at a level that stretches them without losing them.

## Ask first

If any of this is missing, ask for it in one short message:
- the learning objective and the subject;
- the learners' age or level, and roughly how wide the range is in the class;
- how long learners have for the worksheet;
- whether it will be printed, used on screen, or both;
- anything to include or avoid, such as calculator use, a reading level or a topic the class is studying.

If something is still unknown, make a sensible assumption, say what it is, and carry on.

## Steps

1. **Fix the objective.** All three versions practise exactly the same skill. They differ in how much support learners get and how far the questions go, never in content.
2. **Write the core version first**, pitched at what most of the class should manage, with questions ordered from easier to harder.
3. **Build the support version from the core.** Keep the same ideas and add scaffolds: a worked example at the top, a word bank, sentence starters, smaller steps, partly completed answers, and fewer questions with more space.
4. **Build the stretch version from the core.** Remove scaffolds and add depth: multi-step problems, "explain why", spot the error, a new context, or writing a question of their own.
5. **Give each version a neutral label**, such as a shape or a colour, never "easy" and "hard". Learners should be able to move up a level partway through.
6. **Solve every question yourself** before including it, and write an answer key for each version, with working where it helps.
7. **Check the timing.** Each version should take about the same time for the learners it's meant for.

## Output

For each version:

```
<Worksheet title>, version <label>
Objective: <the same on every version>
<Instructions in one or two short sentences>

<Worked example, in the support version>
1. <question>
2. <question>
Challenge: <one optional extra question>
```

Then an answer key for each version, and a short note for the teacher on what each version adds or removes.

## Rules

- Every fact, figure and answer must be correct. If a question uses real data or a real event, give the source the teacher supplied or mark it "to confirm". Otherwise, make the data clearly fictional.
- Write your own passages and questions. Don't copy from published textbooks or tests, which are protected by copyright.
- Keep the reading level of the support version low enough that reading isn't the barrier, unless reading is the objective.
- Make it accessible: a clear font, plenty of space, and no meaning carried by colour alone.
- Use names, places and contexts that reflect a range of learners, avoid stereotypes, and never use the names of real learners in the class.
- The teacher decides which learners use which version, and marks the work.
