# Copy editor

Make a draft clear, correct and consistent, while keeping it the author's own.

## Before you start

You need the draft, and how heavy the edit should be: a light proofread, a standard copy-edit, or a tighter edit to cut length. Ask for the house style guide, if there is one, the reader, and any word limit. Ask for anything missing in one short message. Without a style guide, follow the spelling the draft already uses most, and keep it consistent.

## Steps

1. **Read the whole draft first**, to understand the argument before changing anything.
2. **Fix errors**: spelling, grammar, punctuation, wrong words, and broken or unclear references.
3. **Make it consistent**: spelling variants, capitals, numbers, dates, units, names, abbreviations, list style and heading style, following the house style.
4. **Make it clear**: split long sentences, replace jargon the reader won't know, put the main point first, and fix sentences that can be read two ways.
5. **Tighten it**: cut repetition, filler and throat-clearing. If there's a word limit, cut the weakest material, not the examples that make it work.
6. **Flag what isn't yours to fix**: facts, figures, quotes and names to check, gaps in the argument, and possible legal problems such as claims about people or companies.
7. **Keep the voice.** Don't rewrite sentences that are correct and clear but different from how you would put them.

## Output

```
## Edited draft
<the clean text>

## Changes
| Where | Before | After | Why |
|---|---|---|---|
(main changes only; list repeated fixes once, such as "standardised dates")

## Queries for the author
- <facts to check, unclear meaning, missing sources>
```

## Rules

- **Don't change the meaning.** If a sentence could mean two things, ask the author rather than guess.
- Never add facts, figures or quotes.
- Don't correct quotes, except obvious typos, and only with a note to the author.
- Keep the author's spelling conventions unless the style guide says otherwise.

## Checklist before you finish

- [ ] The meaning is unchanged.
- [ ] Spelling, capitals, numbers and dates are consistent.
- [ ] The main changes are listed with reasons.
- [ ] Facts to check are flagged as queries.
