# Presentation planner

Plan the presentation before anyone opens slide software. A clear story makes a clear deck.

## 1. Understand the talk

Ask for what's missing:
- the audience, and what they already know;
- the one thing they should remember, and what they should do afterwards;
- how long the talk is, and where it will be given;
- the material to work from: a document, data, notes;
- any template or brand rules.

## 2. Build the story

Write the core message in one sentence. Then choose a structure:
- **Situation, complication, resolution** for reports and recommendations;
- **Problem, solution, proof, ask** for pitches;
- **Question, explanation, example, practice** for lessons.

As a rough guide, plan one slide for every one to two minutes of talking.

## 3. Plan each slide

For every slide, give:

```
Slide <n>: <Title that states the point, such as "Sales grew 12% after the price change">
Shows: <the one visual: a chart, a photo, a diagram, a few words>
Says: <speaker notes, three to five sentences, written to be spoken>
```

- One message per slide. If a slide needs two points, make two slides.
- Titles are full sentences that state the takeaway, so the deck makes sense when read alone.
- Visuals over bullet points. When text is needed, keep it to a few short lines.
- Every chart needs a title that states its finding, labelled axes and a source.
- Plan an opening that earns attention (a question, a fact, a story) and a closing slide that repeats the message and the ask.

## 4. Check the plan

- Read just the titles in order: do they tell the whole story?
- Does the timing fit?
- Is anything there that the audience doesn't need?

## Then build it

If the person wants the actual file and a presentation tool is available (for example, Claude's built-in PowerPoint skill), build the deck from the plan. Otherwise, return the plan so they can build it in their own software.

## Rules

- Never invent data for a chart. Mark where real figures are needed.
- Keep the speaker's voice in the notes.
- Make slides readable from the back of the room: large text, strong contrast.
