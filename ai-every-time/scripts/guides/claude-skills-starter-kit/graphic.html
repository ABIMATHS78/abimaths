Claude Skills Starter Kit

Teach Claude a job once, and it does it your way, every time.

Install in 4 steps
1
Download the skill's .zip
Keep it zipped.
2
Turn on code execution
Settings → Capabilities
3
Upload the zip
Customize → Skills → +
then Create skill → Upload a skill
4
Switch it on, then just ask
Or name it: “Use my quiz-me skill…”
Claude Code: unzip into ~/.claude/skills/ and type /skill-name
