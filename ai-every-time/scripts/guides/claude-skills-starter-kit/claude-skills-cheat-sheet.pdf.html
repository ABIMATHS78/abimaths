Claude Skills Starter Kit

by Mojeed Abisiga
from the guide in Guides

1What a skill is

A folder that teaches Claude one job your way: a SKILL.md file with a name, a description and instructions, plus any templates or scripts.

Claude always sees each skill's name and description; it reads the instructions only when a request needs them, and the extra files only if they're needed.

2Install it in Claude

  1. Download the skill's .zip. Keep it zipped.
  2. Settings → Capabilities: turn on Code execution and file creation (Create and edit files in the newer layout).
  3. Customize → Skills → + → Create skill → Upload a skill, then choose the zip.
  4. Switch the skill on.

Enterprise: an owner turns skills on first, in Organization settings → Plugins & skills → Policy.

3Use it

  • Just ask: Claude picks a skill when your request matches its description.
  • To be sure, name it: “Use my quiz-me skill on these notes.”
  • In Claude Code and the Excel, PowerPoint, Word and Outlook add-ins, type / and pick one.
  • Not used? Check its switch is on, name it, or sharpen its description.

4In Claude Code

  • All projects: unzip into ~/.claude/skills/
  • One project: unzip into .claude/skills/ and commit it.
  • Run one with /skill-name; /skills lists them.
  • Skills switched on in your Claude account sync when you sign in with it.

6Make your own

weekly-report/
├─ SKILL.md name, description, steps
├─ reference.md detail read when needed
├─ templates/ files to fill in
└─ scripts/ steps that must be exact

Test it with three requests that should use it and two that shouldn't. If Claude misses one, improve the description first.

7The rules

  • name: lowercase letters, numbers, hyphens; 64 characters at most; no “claude” or “anthropic”; same as the folder.
  • description: what it does and when to use it, in the third person; 200 characters at most in the Claude apps.
  • instructions: under 500 lines; steps, rules, an example, a checklist.
  • zip the folder, so the zip holds weekly-report/SKILL.md.

!Before you switch a skill on

Skills can run code. Install them only from sources you trust, and read every file first, especially scripts and anything that downloads software or sends data to a website. Never put passwords, API keys or personal data in a skill.
